# 🛒 Instamart Sales Analysis Dashboard – Power BI

An interactive **Instamart Sales Analysis Dashboard** developed using **Microsoft Power BI** to analyze sales performance, orders, customer ratings, product categories, city types, shop types, and business trends.

The dashboard provides an easy-to-use interactive interface that helps identify important sales patterns and business insights.

---

![Instamart Sales Dashboard](https://github.com/Adityakaushik-mrt/Power-BI-Dashboard/blob/main/Instamart-Sales-Dashboard/Instamart_Dashboard.JPG?raw=true)

---

## 🎯 Project Objective

The objective of this project is to build an interactive business intelligence dashboard that helps analyze Instamart sales data and understand:

- Overall sales performance
- Total orders and average sales
- Customer rating performance
- Sales by city type
- Orders by city type
- Sales by product category
- Sales by shop type
- Shop opening-year trends
- Performance across different outlet tiers
- Performance across different outlet sizes

---

## 📌 Key KPIs

The dashboard highlights the following key performance indicators:

- 💰 **Total Sales:** ₹1.20M
- 🛍️ **Total Orders:** 8.52K
- ⭐ **Average Rating:** 3.92
- 📈 **Average Sales:** ₹141.01

## 🔍 Dashboard Features

### Interactive Filters

Users can dynamically filter the dashboard by:

- 📅 Year
- 🏪 Shop Size
- 🏬 Shop Type
- 🏷️ Tier

### Sales Analysis

The dashboard provides:

- Total Sales
- Average Sales
- Total Orders
- Average Rating
- Sales by City Type
- Orders by City Type
- Sales by Category
- Sales by Shop Type

### Trend Analysis

The **Shop Opening Year** visual helps analyze how sales performance changes based on the year shops were opened.

### Category Analysis

The category-level sales visualization helps identify the highest and lowest-performing product categories.
